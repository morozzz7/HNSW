- **Дата:** 2026-10-27
- **Этап и задачи плана:** Этап 2, задачи 2.1–2.8
- **Предыдущий отчёт:** `docs/reports/2026-10-26_02_backend_etap-1-yadro-hnsw.md`

## 1. Краткое резюме

Реализован слой данных для курсовой по HNSW: загрузчики векторов (CSV, JSON, .fvecs/.ivecs), синтетические генераторы (uniform, gaussian, clusters), валидация входных данных, in-memory-хранилище датасетов с метаданными и превью, а также PCA-проекция в 2D с кэшем для визуализации графа. Добавлен скрипт скачивания подмножества SIFT. Покрыто юнит-тестами, проходит `go vet`, `gofmt`, `go test`.

## 2. Что сделано

- 2.1 CSV loader — `internal/dataset/loader.go`: парсит строки из чисел с плавающей точкой, первая строка воспринимается как заголовок, если содержит нечисловые поля.
- 2.2 JSON loader — принимает либо массив массивов `[[...]]`, либо объект с полем `vectors`.
- 2.3 `.fvecs` / `.ivecs` loader — формат SIFT/GIST (int32 размерность + элементы), 구분 по расширению файла.
- 2.4 Генератор — uniform [0,1), gaussian N(0,1), кластеры вокруг случайных центров, селективный seed для воспроизводимости.
- 2.5 Валидация — непустой набор, одинаковая размерность, отсутствие NaN/Inf, пределы MaxVectors/MaxDim.
- 2.6 In-memory `Store` — добавление/получение/список/удаление датасетов, безопасный для параллельного доступа (RWMutex), превью первых векторов, статистика min/max/mean по измерениям.
- 2.7 PCA -> 2D — `internal/projection/pca.go`: центрирование, ковариационная матрица, собственный разбор методом Якоби (сортировка по убыванию собственных значений), проекция на первые две главные компоненты; потокобезопасный `Cache` для хранения координат по id датасета.
- 2.8 `scripts/download_sift.sh` — скачивание sift.tgz и вырезка подмножества базы и запросов (не коммитится, данные не в репозитории).

## 4. Ключевые решения

- **Решение:** все на стандартной библиотеке Go, без сторонних зависимостей (в т.ч. без gonum; Якоби реализован вручную).
  **Альтернативы:** gonum `mat`/`eigen` для PCA.
  **Причина:** курсовое требование «от и до», минимизация зависимостей, cukup точности для визуализации.
- **Решение:** расстояния считаются без sqrt, корень только на выходе API; векторы `[]float32`, внутренние id `uint32`.
  **Альтернативы:** float64 на всём пути.
  **Причина:** согласованно с этапом 1 (ядро HNSW) и контрактом `docs/API.md`.
- **Решение:** CSV-заголовок определяется эвристикой (если в первой строке есть нечисловое поле).
  **Альтернативы:** флаг `hasHeader` в запросе.
  **Причина:** проще для клиента, достаточно для курсовой.

## 6. Проблемы и ограничения

- PCA через Якоби — O(dim^3) по итерациям; при очень большой размерности (>> 1024) может быть медленным; для визутации достаточно (SIFT — 128).
- Генератор кластеров использует фиксированное число кластеров (4); параметр числа кластеров можно добавить позднее.
- .fvecs/.ivecs не загружались из реального файла в тесте (создаётся временный), реальный SIFT не скачан (скрипт есть, данные не коммитятся).

## 7. Изменения контракта API / влияние на другую часть
